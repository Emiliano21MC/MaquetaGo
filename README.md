# MaquetaGo

Aplicación Expo + React Native + TypeScript con API Express y MySQL.

- [Instalación y funcionamiento full-stack](FULL_STACK.md)
- App móvil: raíz del proyecto, rutas en src/app
- API: backend/
- MySQL: database/scripts/
- Referencias visuales y prompts: references/

Iniciar API: npm run dev --prefix backend

Iniciar app: npx expo start

En PowerShell restringido usar npm.cmd y npx.cmd.
